# Benchmark Results — Mooré–French Machine Translation

## 1. Evaluation status

A conventional machine-translation benchmark was not conducted because the available local computing resources were insufficient to perform a reliable evaluation of the adapted 70B model.

The evaluation reported here therefore focuses on corpus-level and tokenizer-level analysis rather than automatic translation-quality metrics.

Metrics such as BLEU, chrF, COMET, or comparable translation-quality metrics are not reported.

The present benchmark should therefore not be interpreted as a direct measurement of translation quality.

---

## 2. Tokenization and Corpus Benchmark

A dedicated tokenizer benchmark was conducted before the final evaluation.

The local tokenizer was loaded using `PreTrainedTokenizerFast`, and token counts were obtained with:

```python
tokenizer.encode(
    text,
    add_special_tokens=False
)

Therefore, the reported values correspond to tokens generated by the local tokenizer without additional special tokens.

The original corpus contained 1,176 entries.

2.1 Original corpus
Field	Tokens
Mooré	48,781
French	34,654
Mooré + French	83,435
Enhanced completion	458,393
Total	541,828

The average number of tokens per entry was approximately:

41.48 Mooré tokens per entry
29.47 French tokens per entry
70.95 Mooré + French tokens per entry

Importantly, the Mooré + French parallel fields alone contain 83,435 tokens, which is substantially above the project's 5,000-token minimum.

3. Dataset Anomalies

The tokenizer analysis revealed an important issue in the enhanced_completion field.

Although most sequences were relatively short, six entries contained extremely long repetitive outputs.

The six anomalous entries were:

81, 167, 385, 557, 749 and 964

Their lengths ranged from 11,139 to 18,626 tokens, whereas the next longest examples were below 1,000 tokens.

Manual inspection showed that these were not naturally long linguistic examples but contained substantial repetition.

For statistical analysis, these six entries were therefore excluded without modifying the original dataset.

5. Dataset Adaptation

The cleaned parallel dataset was subsequently imported into AdaptionLab.

The platform was used to prepare the dataset for model adaptation.

During this stage, the dataset initially received a relatively low automated quality score.

The final reported score was:

Quality score: 6/10
Percentile: 3.3%

This result indicates that the dataset was considered low-quality by the platform's automated language-domain comparison.

However, the dataset had undergone extensive manual cleaning and alignment.

The low automated score should therefore be interpreted as a characteristic of the current resource rather than as evidence that the dataset contains no usable parallel information.

The adaptation was nevertheless completed successfully.

6. Model Adaptation

The target model was based on:

Meta Llama 3.3 70B Instruct

The adaptation was performed for the specific task of Mooré–French machine translation.

The adaptation used:

Training method: SFT
Adaptation type: LoRA
Dataset format: Chat
Epochs: 3
LoRA rank: 64
LoRA alpha: 128
LoRA dropout: 0
Learning rate: 0.00005
Warmup ratio: 0.05
Weight decay: 0.02
Maximum gradient norm: 1
Scheduler: cosine
LoRA trainable modules: all linear layers

The resulting trained model was identified as:

adaption_moore_french_parallel

The adapted model was subsequently made available as a LoRA/PEFT adapter rather than as a complete standalone 70B model.

7. Limitations

The principal limitation of this benchmark is the absence of a conventional translation-quality evaluation.

Because the available local computing resources were insufficient for reliable evaluation of the adapted 70B model, automatic metrics such as BLEU, chrF, and COMET could not be computed.

The results presented here should therefore be understood as a corpus and tokenizer benchmark, not as evidence of a specific translation-quality improvement.

Future work should include evaluation on a held-out Mooré–French test set and comparison with the base model.

Such an evaluation would make it possible to quantify translation quality and assess generalization to unseen Mooré text and domains.

8. Reproducibility

Token counts were computed using the local tokenizer through:

tokenizer.encode(
    text,
    add_special_tokens=False
)

The original corpus was preserved, including the six anomalous entries.

The six anomalous entries were excluded only from the cleaned statistical analysis.

The benchmark therefore preserves the distinction between:

the original corpus of 1,176 entries;
the statistical corpus of 1,170 entries;
the core Mooré–French parallel data containing 83,435 tokens;
the additional enhanced_completion data.

This distinction is maintained to support reproducibility and traceability.
